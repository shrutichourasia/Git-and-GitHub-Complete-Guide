# Git & GitHub — Complete Guide

Welcome to the Ultimate Beginner-Friendly Guide for Git and GitHub.
This repository provides clear explanations from basic commands to advanced workflows, including short one-line descriptions for easy learning.

Whether you are a student, developer, or open-source contributor, this guide will help you understand Git with confidence.

---

## What You Will Learn

• What is Git and why it is used
• How to install and set up Git
• Creating and working with repositories
• Staging, committing, pushing and pulling changes
• Branching and merging
• Pull Requests and code collaboration
• Handling merge conflicts
• Undoing and recovering changes
• Stashing temporary work
• Rebase, tags, and cherry-pick
• Industry best practices

## Best Practices

• Commit frequently with meaningful messages
• Always pull before pushing changes
• Use separate branches for features
• Avoid force pushing to shared branches
• Review and test before merging into main
